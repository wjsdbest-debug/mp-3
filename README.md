# MP3 React Resume

This project recreates my MP1 online resume with React and React Router.

## Main features

- Reusable header, navigation, main content, and footer components
- Browser routing with `RouterProvider`
- React calculator built with a custom Hook
- Responsive layout based on the MP1 design

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
